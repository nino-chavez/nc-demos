The memory server is not the memory.

I wanted Claude, Codex, and Gemini to share what they learn across machines. A Cloudflare backend was the easy part. The hard part was deciding what may become memory, who may approve it, and how to prove the raw transcripts never left the machine.

02 THE SCOPE

Three clients. One memory contract.

The first architecture treated one harness as the center and the others as adapters. The correction changed the product: Claude, Codex, and Gemini are equal clients. They write through the same queue and retrieve through the same MCP tools. No model owns the truth.

The governing rule

Project files and shared instructions remain authoritative. Retrieved memory is supporting context with provenance, status, and a path back to its source. A plausible old lesson may inform a session; it may not silently overrule the repo.

03 THE ARCHITECTURE

The transcript stops at the trust boundary

Raw logs are useful for mining and terrible as universal prompt context. The local machine extracts a small, re-redacted candidate first. Cloudflare receives that candidate and its provenance—not the conversation that produced it.

04 THE CONTRACT

Retrieval is not approval

“It matched the query” is not a truth test. Every record carries one of five review states. Approved is the default search surface. The other states remain inspectable because forgetting history is different from pretending it never happened.

Candidate

The system extracted something plausible. It is searchable for review, but it is not injected into ordinary sessions.

05 THE FAILURE

The first scheduled sync proved the gate mattered

The client was baselined before Gemini’s retained sessions finished catching up. The first scheduled run therefore treated old mined lessons as new work. They were redacted candidates, not raw transcripts—but the scope was still wrong.

01

Baseline too early

The cursor recorded an incomplete local database. Nothing in the sync command distinguished first use from a deliberate history import.

16

Old candidates arrived

Sixteen retained lessons crossed the boundary. The ingest receipts made the exact batch identifiable.

✓

Quarantined, then made fail-closed

All sixteen were marked Stale through audited MCP calls. The local baseline moved after catch-up. The staging command now refuses to run without an explicit cursor unless a human requests backfill.

07 THE HARDWARE ANSWER

The Mac mini became optional

“can we just host it in cloudflare with r2 and their ai gateway platform?” operator question, verbatim — the simpler host was already in the room

Cloudflare owns the shared plane

Authenticated ingress, durable queueing, searchable reviewed memory, audit history, and portable snapshots need an always-on public endpoint. Worker, Queue, D1, and R2 cover that job without maintaining a home server.

Each machine keeps the private work

Transcript parsing, local SQLite mining, redaction, and the durable outbox stay beside the source logs. A future local model can help with bulk extraction, but it is an optional worker—not the system’s authority.

AI Gateway is a routing seam

The gateway is configured with payload logging off and zero-data-retention enabled. Model distillation remains disabled until the deterministic ingest path has enough reviewed examples to evaluate it.

A mini still has one honest use

Buy the always-on machine when a measured local workload needs it: private embeddings, large batch extraction, or offline access. Do not buy it to create the illusion of architecture.

08 YOUR VERSION

Start with authority. Add retrieval last.

The tool is worth its own project because it has a real contract, three clients, deployment state, and failure modes. The write-up is worth shipping too—but as evidence of the tool, not a substitute for it.

minimum adoption sequence
1. keep shared instructions in Git              # always-loaded truth
2. finish retained-session catch-up             # all three harnesses
3. baseline the local mining database           # no accidental history import
4. stage redacted candidates into an outbox     # retryable, inspectable
5. ingest as Candidate and review               # human authority
6. retrieve Approved records through MCP        # provenance attached
7. measure before enabling model distillation   # quality, privacy, cost
