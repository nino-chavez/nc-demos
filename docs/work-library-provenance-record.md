# Put Provenance Labels on AI Research

## Decision

Make the evidence condition visible beside every load-bearing claim. A reader should be able to tell whether the source was read directly, only corroborated through search, or could not be verified.

## Why it belongs in the Work Library

Agent-assisted research can produce a polished recommendation whose evidence is still vendor marketing. The source demo shows that a second pass can repeat the error with a competitor's marketing. The reusable method is to re-derive claims from their sources, identify who owns each source, downgrade the label when direct inspection is blocked, and test whether the recommendation survives the downgrade.

## Practical rule

- Put the evidence label next to the number or claim it qualifies.
- Separate a page read at the source from a search result about that page.
- Treat vendor and competitor content as interested evidence.
- Preserve the limitation when a source blocks direct inspection.
- Change or withdraw the recommendation if it does not survive weaker evidence.

## Boundary

This is a publication and review discipline. It does not make an unverified claim true, replace subject-matter judgment, or authorize a decision by itself.

## Next proof

Apply the labels to each new executive research package, then have the owner challenge one load-bearing claim by re-reading its primary source before publication.
